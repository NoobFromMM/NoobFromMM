## 🔁 My Claude Code workflow

```text
1. Write a spec          → spec.md defines "done"
2. Pick a methodology    → Superpowers (skills + agents + MCP)
3. Build in small slices → one file, one commit
4. Review with agents    → profile-reviewer checks every change
5. Polish with skills    → ui-ux-pro-max tightens the visuals
6. Ship and reflect      → commit, push, document what I learned
```

All the tooling lives in the [`.claude/`](./.claude/) directory — reusable
across future chapters.
